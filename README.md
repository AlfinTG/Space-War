# 🚀 Space War

A simple 2D space shooter game built with **Python and Pygame**.

The player controls a spaceship, fights enemy ships, avoids incoming attacks, and tries to achieve the highest possible score.

## 🎮 Features

- 🚀 Player-controlled spaceship
- 👾 Enemy spaceships
- 🔫 Shooting and enemy attacks
- 💥 Collision detection
- 🏆 Score tracking
- ❤️ Player health/lives system
- 🎯 Increasing gameplay challenge
- 🎵 Game sound effects *(if enabled in the project)*
- 🔄 Restart/replay support

## 🛠️ Technologies Used

- **Pygame**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Open the project

```bash
cd Space-War
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

Or install Pygame directly:

```bash
pip install pygame
```

### 4. Run the game

```bash
python main.py
```

## 🎮 Controls

| Key | Action |
|---|---|
| `↑` / `W` | Move Up |
| `↓` / `S` | Move Down |
| `←` / `A` | Move Left |
| `→` / `D` | Move Right |
| `SPACE` | Shoot |
| `ESC` | Quit |

> Controls can be updated here to match the final implementation.

## 🏆 Gameplay

The objective is simple:

**Destroy enemies → survive attacks → score as high as possible.**

As the game progresses, avoiding enemy attacks and positioning the spaceship effectively become increasingly important.

## 📦 Requirements

- Python **3.x**
- Pygame **2.6.1** *(or the version specified in `requirements.txt`)*

## ▶️ Running From Source

After installing Python and the required packages, run:

```bash
python main.py
```

The game window should open and the game can be played directly.
